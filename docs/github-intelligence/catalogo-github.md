## Uso responsável
- Não copiar interfaces fechadas ou usar código sob licenças incompatíveis. Twenty e Outline exigem análise específica antes de reaproveitar código.
- Não adotar pacote apenas por popularidade. Examinar releases, manutenção e advisories.
- Não migrar stack atual do NEXUS só para utilizar a novidade do momento.
- Agentes/skills não substituem ferramentas reais, banco, testes ou autorização.
- Reavaliar projetos arquivados antes de recomendar; AutoGen e Continue já foram sinalizados na pesquisa anterior.
