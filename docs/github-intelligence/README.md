# GitHub Intelligence integrado ao NEXUS CRM
Biblioteca de engenharia, design profissional, IA, agentes, Agent Skills e repositórios para evolução do CRM. Preservada no código-fonte, sem alterar o comportamento de runtime sozinha.

Arquivos:
- [Prompt mestre](PROMPT_MESTRE.md): regras para arquitetura, pesquisa, segurança, CRM, UX, IA, RAG, MCP e validação.
- [Catálogo GitHub](catalogo-github.md): repositórios recomendados, URLs e critérios de uso responsável.
- [Arena Skill](arena-skill.md): revisão competitiva do ZIP disponibilizado pelo usuário.
- [Plano NEXUS](PLANO_NEXUS.md): aplicação concreta e roadmap.
- [Instruções do agente](../../AGENTS.md): contexto de produto.
- [Skill local](../../.agents/skills/github-intelligence/SKILL.md): procedimento modular para ferramentas compatíveis.

**Importante:** documentação e `SKILL.md` não dão acesso a APIs, não habilitam agentes automaticamente, não instalam nenhuma dependência, nem significam integração com Segundo Cérebro. Para uso: agente de programação com acesso autorizado ao GitHub/código, terminal, testes e integrações específicas. Revalidar atualizações e licenças antes de adicionar projetos.
